# docs/ — Context

## Purpose
Architecture documentation, API docs, decision log, and any guides for working on the project. Not application code.

## What lives here
- **`decisions.md`** — Every major architectural or technology decision, with date and reason
- Future: `api.md` (Supabase Edge Function API reference), `onboarding.md`, etc.

## Rules
- Markdown only — no code files here
- `decisions.md` must be updated whenever a major architectural choice is made, a significant dependency is added or removed, or the project structure changes
- Keep docs in sync with code — if a decision is reversed, update the log
